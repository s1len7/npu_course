실습 문제: 사전 학습된 MobileNetV2 모델의 이미지 전처리 구성


PyTorch의 torchvision 라이브러리에서 제공하는 MobileNetV2 모델을 활용하여 여러 이미지에 대한 객체 분류 및 추론 성능을 측정하려고 합니다.

MobileNetV2는 ImageNet 데이터셋을 이용하여 사전 학습된 모델이며, 학습 과정에서 정해진 이미지 크기와 정규화 기준을 사용합니다.

따라서 새로운 이미지를 모델에 입력할 때에도 사전 학습에 사용된 기준에 맞게 전처리해야 합니다.

현재 다음과 같이 MobileNetV2의 사전 학습 가중치를 설정했습니다.

from torchvision.models import MobileNet_V2_Weights

weights = MobileNet_V2_Weights.DEFAULT


이 가중치에 적합한 이미지 전처리 과정에는 다음 작업이 포함되어야 합니다.

1. 이미지 크기 조정(Resize): 모델에서 요구하는 크기에 맞게 이미지 크기를 조정합니다.
2. 중앙 영역 추출(CenterCrop) 이미지 중앙에서 모델 입력에 필요한 영역을 추출합니다.
3. 텐서 변환(ToTensor): 이미지 데이터를 PyTorch Tensor로 변환하고 픽셀값을 적절한 범위로 조정합니다.
4. 정규화(Normalize): 사전 학습 과정에서 사용한 평균과 표준편차를 적용합니다.

위 작업을 각각 직접 구현하지 않고, `weights` 객체에서 제공하는 기능을 사용하여 **해당 가중치에 적합한 전처리 파이프라인을 자동으로 생성**하려고 합니다.

[요구사항]

- weights 객체가 제공하는 메서드를 사용해야 합니다.
- 전처리 과정은 가중치에 정의된 설정을 자동으로 적용해야 합니다.
- 생성한 전처리 객체를 `preprocess` 변수에 저장해야 합니다.
- 실제 이미지에 전처리를 적용하는 것이 아니라, 이후 여러 이미지에 반복적으로 사용할 수 있는 전처리 객체를 생성해야 합니다.
