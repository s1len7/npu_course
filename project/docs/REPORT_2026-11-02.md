# 밤사이 작업 보고 (2026-11-02)

## 결론

**STT는 CPU Whisper로 확정.** Hailo NPU로 STT를 돌리는 것은 실패해서 원래대로 되돌림.

## 아침에 할 일

1. **HA에 음성 연결:** Pi HA(`http://192.168.0.65:8123`) → 설정 → 기기 및 서비스 → 통합 추가 → **Wyoming Protocol** 두 번
   - STT: `127.0.0.1` / `10300` (CPU Whisper)
   - TTS: `127.0.0.1` / `10200` (Piper 한국어)
   - 설정 → 음성 비서에서 위 두 개 선택
2. **시간 날 때 Pi 재부팅 한 번** (실패한 시험 때 커널 경고가 남아 있음, 지금 동작은 정상)

## Hailo STT를 버린 이유

- Hailo Whisper 자체는 CPU보다 3~6배 빠름 (짧은 명령 0.6~1.3초 vs 3.6~4.5초), 정확도는 같음
- 하지만 Frigate와 NPU를 같이 쓰게 만들면, **둘이 동시에 추론하는 순간 Hailo 드라이버가 커널 경고를 초당 수백 건 쏟아내고 STT가 멈춤**
- 시험 방법: Frigate에 Hailo 예제 영상(사람이 걷는 영상)을 넣어 계속 감지시키면서 STT 20회 요청
- 이 장비에서는 NPU를 Frigate 하나만 쓰는 게 안전함

## 정리한 것

- Frigate: 원래 버전 하나만 남김 (감지 10ms, 정상)
- 지움: NPU 공유용 Frigate 이미지·설정, Hailo STT 서버(`stt_hailo`), 실험용 venv(1GB), 빌드 캐시(3GB)
