## 1. 된 것

- Frigate 카메라 fps를 5에서 10으로 올림 → 10fps 동작 확인
- Pi HA에 STT(Whisper)·TTS(Piper 한국어) 컨테이너 추가, 둘 다 실행 중
  - Pi 안에서만 접속 가능 (LAN에 열지 않음)

## 2. Hailo Whisper 실험 결과

| | Hailo NPU | CPU (지금 사용 중) |
|---|---|---|
| 속도 (2~3초 문장) | **0.6~1.7초** | 4~5.4초 |
| 정확도 | 비슷함 (둘 다 "현관에" → "형가리") | 비슷함 |

**결론: Hailo가 5배 빠르지만 지금은 못 씀.**
- Frigate가 NPU를 혼자 차지해서, Frigate가 켜져 있으면 Whisper가 NPU를 못 씀
- NPU를 같이 쓰려면 Frigate 안의 HailoRT를 "공유 기능"을 켜고 다시 빌드해야 함
- 이 빌드(HailoRT 소스 빌드)는 Claude Code 자동 모드가 막아서 진행 못 함

**선택지**
- A. 빌드 허락 → 제가 Frigate용 HailoRT를 다시 빌드하고 Whisper를 Hailo로 전환
- B. 지금처럼 CPU 사용 (짧은 명령에 4~5초)
